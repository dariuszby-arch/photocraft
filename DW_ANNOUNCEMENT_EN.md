# Community announcement draft — DW 2

Prepared for review; this file does not mean the message has been posted.

---

My unofficial PhotoCraft community build is now available as **0.20.2 DW 2** for Windows x64 and Linux/MX Linux 23.

It includes JPEG XL read/write, lossless/lossy output, quality and Fast/Normal effort settings, plus the integrated Batch Converter:
**File → Export → Batch Converter…**

Add individual files or a filtered folder, choose images with checkboxes, select one output format for the whole queue, set the destination, and follow progress and per-file results. The converter supports cancellation and protects source files.

DW 2 also improves JPG ↔ JXL EXIF/XMP handling and colour-profile preservation. Use **Metadata: All** and turn **Remove location info** off when you want to retain location metadata.

Downloads, source archives and checksums:
https://github.com/dariuszby-arch/photocraft/releases/tag/v0.20.2-dw2

This is an unofficial fork, with full credit to the original PhotoCraft authors and contributors. Feedback on real-world files is welcome.
